This repository serves as a simple ping-pong example of contract testing using pact-python package.

We test the contract between two applications that in deployment environment should talk to eachother over a message broker (here it's kafka, but that doesn't matter).

Besdies the relatively simple and primite app1 and app2 structures we provide two test files.

The first one `test_contract.py` provides means to generate a contract file using source code provided by the "consumer".
The second one `test_provider.py` utilizes this pact contract json file to test wether the Message object generated by app1 actually conforms to the contract requirements.
